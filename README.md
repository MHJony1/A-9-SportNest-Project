## 🎯 Purpose

PlayNest is a full-stack sports facility booking platform where users can discover, filter, and book sports arenas — including football turfs, cricket grounds, badminton courts, volleyball arenas, and more. Venue owners can list and manage their facilities, while users can seamlessly reserve slots and track their bookings in real time.

---

## ✨ Features

- 🔐 **Authentication System** — Secure login, registration, and logout using Better Auth with session-based token management
- 🏟️ **All Facilities Page** — Browse all available sports venues with advanced search, filtering, sorting, and pagination
- 📄 **Facility Details Page** — View full details of a venue including images, pricing, available slots, capacity, and live booking count
- 📅 **Smart Booking System** — Select date, time slot, and duration with dynamic fee calculation and real-time slot confirmation
- 📋 **My Bookings Page** — Track all personal reservations with status, date, slot, duration, and total fee — with cancellation support
- 🛠️ **Manage Facilities** — Venue owners can create, edit, update, and delete their own facility listings from a dedicated dashboard
- ➕ **Add Facility** — Owners can list new venues with full details including images, pricing, capacity, and available time slots
- 🔢 **Live Booking Count** — Real-time booking counter displayed on facility cards, updated automatically on every new booking
- 📱 **Fully Responsive UI** — Optimized layout for mobile, tablet, and desktop with smooth animations via Framer Motion
